# AO3401A migration — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace IRLZ44N with AO3401A (P-MOS high-side + NPN), enable 8 h deep sleep, and verify the circuit in stages without damaging the sensor or MT3608.

**Architecture:** Stage 0 = continuity tests without cell. Stage 1 = USB + `enable_deep_sleep: false` + full logs. Stage 2 = battery + 8 h deep sleep + HA monitoring. Firmware drives GPIO4 → NPN → P-MOS Gate; HIGH = sensor ON, no `inverted`.

**Tech Stack:** ESPHome 2026.8, ESP32 Arduino (`toolchain: platformio`), AO3401A, 2N3904/BC547, MT3608, JSN-SR04T-V3.3.

## Global Constraints

- Control: GPIO4 **HIGH** = sensor ON; **no** `inverted` on `sensor_power`
- `sleep_duration: 8h` (active from stage 2)
- `pin_sensor_power: GPIO4` — unchanged
- **Do not** wire OUT+ directly to DRAIN without SOURCE (rejected N-MOS high-side)
- **Do not** wire Q1 on MT3608 IN−
- Sensor GND **direct to GND** (not through MOSFET)
- R1 10k: Gate → OUT+ (pull-up); R2 10k: GPIO4 → NPN base
- DevKit **without** expansion board
- Charger + solar panel — out of scope
